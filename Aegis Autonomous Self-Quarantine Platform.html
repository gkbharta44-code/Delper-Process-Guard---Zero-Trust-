Threats 01–10

Identity, directory and access

Catalyst
A 15x spike in device code phishing and OAuth credential harvesting that bypasses conditional access.
Quarantine
On a token reuse pattern across physically impossible locations, the platform calls the identity provider API to invalidate all refresh tokens and kill live browser sessions.

Threats 11–20

Endpoint, host and compute

Catalyst
Fast lateral movement, with automated persistence scripts that erase diagnostic tracks.
Quarantine
On shadow copy deletion or process memory injection, the host agent kills the process and cuts local routing. One out-of-band forensics tunnel stays open.

Threats 21–29

Cloud infrastructure and microservices

Catalyst
Misconfigured AWS and Azure environments used to compromise tenant metadata and spawn unmanaged crypto miners.
Quarantine
A bucket opened to public read reverts to a private ACL at once. For wider tenant intrusions, the platform rotates provisioning IAM secrets and terminates affected serverless or container instances.

Threats 30–37

AI infrastructure and LLMs

Catalyst
Over 90 organizations have had internal AI systems exploited through prompt injection and jailbreaks.
Quarantine
When a query shows extraction or injection traits, the guardrail drops the calling token’s rate limit to 0 and revokes app-layer session permissions.

Threats 38–45

Operational technology and edge

Catalyst
A 42% year-over-year rise in zero-day exploitation of edge infrastructure used to bridge segmented OT zones.
Quarantine
Temporary null routes block scanning botnets. If a PLC receives unsigned firmware, its switch port moves to a sterile VLAN so the plant floor keeps running.

Threats 46–52

Application, network and data supply chain

Catalyst
Altered Spider-linked eCrime poisoned more than 300 unique software dependencies in a single window.
Quarantine
Unauthorized dependency or script changes halt the CI/CD line and invalidate compiled binaries. Web parameter attacks make the WAF drop packet strings at the perimeter.

Production requirements

Ultra-low-latency telemetry

The SIEM or data lake must parse telemetry from chip registers, cloud control planes and endpoint sensors in under one second.

Bi-directional root API access

The engine needs persistent root-level write access to identity providers, EDR controllers, cloud virtualization planes and core network hardware, so it can inject defenses without waiting for approval.

Context-aware safety interlocks

Before any high-impact script runs, playbooks must check cross-domain correlation. This stops false positives from causing a self-inflicted outage, such as halting a production database.
